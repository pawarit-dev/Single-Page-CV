# Single-Page CV

A simple single-page CV built with HTML.

## Run the project

No build tools or dependencies are required.

1. Clone or download the repository.
2. Open [single-page-cv.html](./single-page-cv.html) directly in a web browser.

Alternatively, serve the project locally:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000/single-page-cv.html>.
